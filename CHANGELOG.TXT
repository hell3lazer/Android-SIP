Version 1.4 (Build 151)
	* Dynamic calling account availability:
	  - When Android SIP is offline, disconnected, unconfigured, or disabled, calling account capabilities are dynamically removed (capabilities = 0) so Android Telecom automatically prompts native SIM selection for calls instead of routing to an unavailable account.
	  - Restored real-time Telecom PhoneAccount updates on registration state changes across the SIP engine lifecycle.
	  - Outgoing connections now validate registration synchronously, rejecting offline attempts immediately without spurious dialing screens.
	* Profile management:
	  - Added manual "Enable Account" toggle option inside each SIP account profile (SIP Account 1 & SIP Account 2).
	  - Disabling a profile cleanly unregisters from the SIP server and transitions the account to an inactive/disabled state without losing saved credentials.
	  - Added "(Disabled)" status indicators and disconnected icons in account summaries when manually turned off.

Version 1.3 (Build 150)
	* Fixed incoming call ringtone: eliminated static noise and Samsung vibration-only issue by delaying audio/RTP hardware activation until the call is actively answered.
	* Native system default ringtone playback: incoming calls now use tel: scheme URI in Telecom, cleanly matching contacts and playing the user's default system ringtone.
	* Fixed first-call failure / cold-start calling:
	  - Restored active UDP keepalives across all modern Android versions (60s UDP / 300s TCP keepalives).
	  - Outgoing calls now asynchronously await SIP registration on cold-start or idle wake before placing calls, eliminating the "SIP Offline" drop.
	* Complete elimination of persistent background notifications and legacy notification channels.
	* Stripped 16 obsolete/unused permissions carried over from legacy Sipdroid.
	* Modern adaptive app launcher icon integrated with full multi-density mipmaps and vector layers.
	* Code and bulk cleanup: removed legacy phone package, dead UI/test activities, obsolete layouts, drawables, and scratch assets.

Version 1.2 (Build 149)
	* Fixed one-way outgoing call uplink audio (receiver can now clearly hear caller).
	* Removed double AEC/NS effect processing on Samsung cellular audio routing.
	* Directly routed microphone PCM to RTP codec encoding, removing legacy ringback substitution.
	* Implemented three-state account registration indicator (Green = Connected, Yellow = Registering, Red = Disconnected).
	* Added instant offline detection on network loss with real-time UI/Telecom refresh.
	* Added configurable Microphone Gain setting in Advanced Options (1.0x to 4.0x).
	* Added RECORD_AUDIO permission validation guard before placing Telecom calls.

Version 1.1 (Build 148)
	* Fixed bidirectional RTP transmission and eliminated socket address locking.
	* Fixed AudioTrack buffer underruns by decoupling volume persistence from audio loop.
	* Native Telecom integration with native cellular audio mode (MODE_IN_CALL).
	* Automatic E.164 phone number formatting for native dialer contacts.
	* Streamlined speaker and earpiece routing transitions mid-call.
	* Suppressed mid-call SIP churn on Wi-Fi/cellular radio capability changes.
	* Migrated to private release signing configuration.
